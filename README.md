#Project Objective

The objective of this project is to automate code refactoring using Artificial Intelligence, reducing manual effort while improving code quality and maintainability.

# AI-Powered Code Refactoring Tool

## Overview
This project is an AI-powered code refactoring tool developed using Python, Streamlit, and Ollama. It helps developers improve code quality, readability, and maintainability by generating optimized code suggestions using Large Language Models (LLMs).

## Features
- AI-based code refactoring
- Code optimization suggestions
- Improved code readability
- Streamlit user interface
- LLM integration using Ollama
- Easy-to-use workflow

## Technologies Used
- Python
- Streamlit
- Ollama
- Large Language Models (LLMs)
- Git
- GitHub

## How It Works
1. User enters source code.
2. AI analyzes the code.
3. Refactored code is generated.
4. User compares original and optimized code.

## Benefits
- Saves development time
- Improves code quality
- Encourages clean coding practices
- Helps developers learn better coding standards

## Future Enhancements
- Bug detection
- Security analysis
- Multi-file refactoring
- Cloud deployment
